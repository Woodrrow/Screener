Read this before trusting any number above.
  • This is a paper-trading research tool. It never places an order and holds no exchange credentials.
  • A forward record under roughly six months cannot separate edge from noise. The sample size is printed beside every statistic for that reason.
  • Slippage is a flat 30bps per side, not a modelled order book — generous for large caps, optimistic for small ones.
  • Reported 24h volume includes wash trading on some venues, which flatters the liquidity factor for coins listed on the worst offenders.
  • Any backtest built from this universe is survivorship-biased: it cannot see coins that died before the snapshot was taken.
